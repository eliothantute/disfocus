# DISFOCUS

Site vitrine 3D immersif pour l'artiste et producteur DISFOCUS.

**Live :** https://disfocus.vercel.app

- Scène WebGL plein écran avec shaders GLSL sur mesure
- Visuels audio-réactifs via la Web Audio API
- Animations au scroll avec GSAP, galerie de sessions vidéo

**Stack :** Three.js, WebGL / GLSL, Web Audio API, GSAP, Vite, Vercel

> Les vidéos (`public/assets/videos/`) et le kit presse ne sont pas versionnés à cause de leur poids.

```bash
npm install
npm run dev
```
